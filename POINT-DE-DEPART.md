# Point de départ du TP 05

Votre point de départ est votre propre projet à la fin du TP 04 : `Fournisseur` et `Adresse`
dans `domain`, `FournisseurDaoJdbc` derrière l'interface `FournisseurDao`, `Tx` et `Db` qui
fonctionnent, et le `pom.xml` du TP 01, qui déclare déjà Hibernate.

Si votre projet n'est pas terminé, partez de `projet-starter/` : c'est cet état, complet, qui
compile et s'exécute. Mode d'emploi dans son `README.md`. Lisez ce code avant de continuer :
les TP suivants supposent que vous l'avez compris.
